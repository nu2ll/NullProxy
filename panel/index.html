منابع سرور

«بررسی از سرور» یه ClientHello واقعی Fake-TLS می‌فرسته و پاسخ خود پروکسی رو چک می‌کنه (نه فقط باز بودن پورت). برای «تست از دستگاه من» VPN رو خاموش کن. مطمئن‌ترین نشونه «کاربر واقعی»ه. TCPی که جواب نمیده رو «تعویض» کن، بدون ری‌دیپلوی.

افزودن دستی (بدون توکن)

اگه TCP رو خودت توی Railway ساختی: آدرس، پورت عمومی و پورت داخلی‌ای که بهش دادی ().
همه‌ی TCPهای Railway یه‌جا لیست میشن و همه‌شون همزمان چک میشن، بدون محدودیت تعداد. TCPهای همین پنل با ClientHello واقعی Fake-TLS تست میشن. برای TCPهای سرویس‌های دیگه فقط باز بودن پورت معلومه، چون Railway پورت رو همیشه باز نشون میده.

کانال‌های اسپانسر

هر کانال یه تگ جدا داره. تلگرام تگ رو برای هر سرور پروکسی می‌گیره، برای همین هر کانال یه پروسه‌ی جدا میشه و توی تب TCP ها برای هر TCP انتخاب می‌کنی کدوم کانال نشون داده بشه. TCPهایی که انتخاب نشدن از کانال پیش‌فرض (★) استفاده می‌کنن. حداکثر کانال.

راهنمای ساخت تگ

  1. توی تلگرام به @MTProxybot پیام بده و /newproxy بفرست.
  2. آدرس و secret پایین رو براش بفرست.
  3. تگی که میده رو همین‌جا با یه اسم ذخیره کن.
  4. توی ربات: /myproxies ← پروکسیت ← Set promotion ← چنل.
  5. برای کانال بعدی، دوباره /newproxy با آدرس یه TCP دیگه بزن.
