# Null Proxy

پروکسی MTProto تلگرام (Fake-TLS) + **SOCKS5** + **چند چنل اسپانسر همزمان** + پنل مدیریت فارسی (سیاه و سفید).
TCPها از خود پنل ساخته، تست، تعویض و حذف میشن. نیازی به ری‌دیپلوی نیست.

## راه‌اندازی (فقط یه بار)
1. فایل‌ها رو توی ریپوی گیت‌هاب جایگزین کن و push کن. Railway خودش دیپلوی می‌کنه.
2. Railway ← سرویس ← Settings ← Networking: **Public Domain** ← پورت `8080` (پنل)، TCP Proxy قبلیت روی `3128` بمونه.
3. **Volume** ← مسیر `/data` (کاربرها، مصرف و تنظیمات نگه داشته میشن).
4. (اختیاری) Variables ← `ADMIN_PASSWORD`. اگه نذاری، رمز توی Deploy Logs چاپ میشه.
5. وارد پنل شو ← تنظیمات ← **توکن Railway** رو بذار (Account Settings ← Tokens ← Create Token).

## چند چنل اسپانسر
- توی تب «اسپانسر» هر چند تا تگ (تا ۸ تا) با یه اسم ذخیره کن و یکی رو پیش‌فرض (★) بذار.
- توی تب «TCP ها» برای هر TCP کانال دلخواه یا «بدون اسپانسر» رو انتخاب کن. کاربر با هر لینکی وصل بشه، چنل همون TCP رو می‌بینه.
- پشت صحنه برای هر تگ یه پروسه‌ی mtprotoproxy جدا اجرا میشه و پورت ورودی هر TCP به پروسه‌ی خودش میره. کاربرها، مصرف و سقف‌ها بین همه مشترکن.
- برای هر تگ جدید توی @MTProxybot یه `/newproxy` جدا (با آدرس یه TCP دیگه) بزن.

## SOCKS5 (برای همه‌جا)
- توی تب «TCP ها» دکمه‌ی **TCP جدید (SOCKS5)** یه TCP می‌سازه که SOCKS5 میده. هر TCP موجود رو هم با انتخاب «نوع پروکسی» می‌تونی بین MTProto و SOCKS5 عوض کنی.
- ورود با یوزر و پسورد: یوزر همون اسم کاربر پنله و هر کاربر یه پسورد SOCKS5 جدا داره (از «بیشتر» ← «پسورد SOCKS5 جدید» عوضش کن). کاربرها، مصرف، سقف ترافیک، سقف اتصال و انقضا بین MTProto و SOCKS5 مشترکه.
- توی «لینک‌ها»ی هر کاربر، آدرس `socks5://user:pass@host:port` (برای مرورگر، سیستم و هر برنامه‌ای) و لینک تلگرام (`t.me/socks`) هست.
- فقط TCP و دستور CONNECT پشتیبانی میشه (UDP نه، چون TCP Proxy ریلوی فقط TCP رد می‌کنه).
- امنیت: بدون لاگین کار نمی‌کنه و وصل شدن به آدرس‌های داخلی (localhost، شبکه‌ی خصوصی ریلوی، ...) بسته‌ست. فقط برای تست محلی می‌شه با `SOCKS_ALLOW_PRIVATE=1` بازش کرد.
- پروب سلامت برای SOCKS5 یه handshake و لاگین واقعی می‌کنه.

## تب Railway (همه‌ی TCPها)
- لیست همه‌ی TCPهای Railway یه‌جا میاد و همه‌شون **همزمان** چک میشن، بدون محدودیت تعداد. نتیجه‌ی هر کدوم همون لحظه که برسه نشون داده میشه.
- «بررسی زنده» پشت سر هم چک می‌کنه (بدون صبر ۶۰ ثانیه‌ای). با دکمه‌ی توقف می‌تونی خاموشش کنی. «بررسی همین الان» یه دور چک می‌کنه.
- با **Account token** کل اکانت دیده میشه. با Project token فقط همون پروژه.
- TCPهای همین پنل با ClientHello واقعی Fake-TLS تست میشن. برای TCPهای سرویس‌های دیگه فقط باز بودن پورت معلومه.
- فیلتر «سالم / مشکل‌دار»، جستجو و «کپی سالم‌ها» هم هست.

## پینگ و وضعیت واقعی
«بررسی از سرور» فقط باز بودن پورت رو نمی‌بینه: یه ClientHello معتبر Fake-TLS می‌فرسته و باید خود پروکسی جواب بده. پینگ نمایش‌داده‌شده زمان همین پاسخه.
بررسی TCPهای پنل هر ۵ ثانیه انجام میشه (متغیر `CHECK_INTERVAL`، حداقل ۲). معتبرترین نشونه همچنان ستون «کاربر واقعی»ه.

## نکته‌ها
- به‌صورت پیش‌فرض تا ۱۰۰ TCP (پورت‌های داخلی 3128 تا 3227). برای بیشتر، `MAX_ENDPOINTS` رو بذار (حداکثر ۱۰۰۰). لیست و چک تب Railway سقف نداره.
- AD_TAG قدیمی (v3 یا متغیر `AD_TAG`) خودکار به اسپانسر `main` تبدیل میشه.
- «تست از دستگاه من» تقریبیه و با VPN خاموش معنی داره.
